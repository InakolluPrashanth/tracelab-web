Frequently asked

Is this a real compiler?

Python and JavaScript can execute in the browser, HTML/CSS render in the preview, and the other supported languages use the connected execution backend.

Where does my code run?

Browser languages run locally. Hosted languages are sent to the TraceLab backend when you press Run.

Can I use this to teach?

Yes. The visual flow is designed to make loops, decisions and data structures easier to understand.

Does the flow change for DSA programs?

Yes. TraceLab detects common sorting, searching and data-structure patterns and builds a data-aware flow.
