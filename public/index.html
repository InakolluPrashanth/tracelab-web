Frequently asked

Is the output real?

Yes. Browser languages execute locally and the hosted languages are sent to the configured execution provider through the backend.

Where does hosted code run?

The browser sends the source to the TraceLab backend only when you run a hosted language.

Is the flow a debugger?

The visual flow explains the execution stages. It is separate from the actual compiler/runtime execution.

Does TraceLab support stdin?

Yes. Hosted programs can receive the text entered in the Program input box.
