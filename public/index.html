How it works

Three steps between a blank editor and a traced program.

1

Write or paste code

Start from the built-in example or bring your own. TraceLab keeps line numbers so you can follow along.

2

Pick a language, or let TraceLab guess

Choose from 16 supported languages, or hit Auto-detect to match your code against language signatures on the spot.

3

Run it

Python and JavaScript execute for real in the browser. HTML/CSS render in the browser. The remaining languages execute through the TraceLab backend.

Frequently asked

Is this a real compiler?

Yes. Python and JavaScript execute in the browser, HTML/CSS render in the browser, while the other supported languages use the connected execution service for real compile/run output.

Where does my code run?

Your source code is sent to the TraceLab execution backend only when you run a server language. The backend forwards it to an isolated execution provider and returns stdout/stderr.

Can I use this to teach a class?

Yes — it's built for walking through control flow one step at a time.

Will more languages get real execution?

The playground now supports a connected execution service for the non-browser languages. The backend keeps the execution API key private.
