Frequently asked

Is the output real?

Yes. Browser languages execute locally and hosted languages are sent to the TraceLab backend.

Can programs receive input?

Yes. TraceLab highlights the input area when the program contains a recognized input operation.

Does Python input work?

Python input() is connected to the input field through the Pyodide standard-input handler.

Where does hosted code run?

Hosted source is sent to the TraceLab backend, which forwards it to the configured execution provider.
