How it works

Three steps between a blank editor and a traced program.

1

Write or paste code

Start from the built-in example or bring your own. TraceLab keeps line numbers so you can follow along.

2

Pick a language, or let TraceLab guess

Choose from 16 supported languages, or hit Auto-detect to match your code against language signatures on the spot.

3

Run it

Python, JavaScript, HTML, and CSS execute for real. The remaining languages are compiled or interpreted through a sandboxed execution service.

What actually runs

TraceLab is upfront about how each supported language is executed.

Live

Python

Runs for real using Pyodide, a full Python build compiled to WebAssembly. The first run loads the runtime in your browser; after that it's instant.

Live

JavaScript

Runs in a sandboxed frame right in your browser. console.log output shows up in the console, for real — nothing is sent to a server.

Live

HTML & CSS

Renders in an inline preview as you edit, with an "Open in browser" button to view the full page in its own tab.

Frequently asked

Is this a real compiler?

Yes. Python, JavaScript, HTML, and CSS execute in the browser, while the other supported languages use the connected sandbox execution service for real compile/run output.

Where does my code run?

Your source code is sent to the TraceLab execution backend only when you run a server language. The backend forwards it to an isolated sandbox and returns stdout/stderr.

Can I use this to teach a class?

Yes — it's built for walking through control flow one step at a time, which works well alongside live instruction.

Will more languages get real execution?

The playground now supports a connected execution service for the non-browser languages. For this free launch, the Node backend keeps the execution API key private; the free provider is intended for demos and light usage.
