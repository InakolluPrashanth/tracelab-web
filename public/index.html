Frequently asked

Is this real execution?

Yes. Browser languages run in the browser and the hosted languages are sent to the TraceLab execution backend.

Where does my code run?

Server languages are sent to the TraceLab backend only when you press the Analyze button.

Can multiple people use it?

Yes. Each execution request is handled independently. The backend does not use one shared code state for all visitors.

Why can the first request be slow?

The free Render service can sleep when unused. The first request after sleeping may therefore take longer.
