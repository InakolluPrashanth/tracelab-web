FAQ

Is the output real?

Yes. Python and JavaScript execute in the browser; the other executable languages are sent to the TraceLab backend and then to the configured execution provider.

Is the API key public?

No. The OneCompiler key belongs only in the Render environment, never in this HTML file.

Can I publish the site?

Yes. Netlify can host the frontend publicly while Render hosts the Node backend.

Is the flow a debugger?

No. It is a language-aware educational visualization. Compiler/interpreter output remains the source of truth.
