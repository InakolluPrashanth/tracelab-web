Frequently asked

Does the flow change for different algorithms?

Yes. The analyzer looks at the source structure and creates algorithm-specific trace steps when it can identify a known pattern.

What if the code is not a known algorithm?

TraceLab falls back to a source-driven control-flow trace instead of pretending the program is a sorting algorithm.

Can I edit after publishing?

Yes. Replace the index.html on Netlify and publish a new deployment; the public URL can stay the same.

Does the backend execute hosted languages?

Yes. Hosted-language requests are sent to the TraceLab backend.
